# Password Generator (Python)

Generates secure random passwords with optional digits and symbols. Uses the `secrets` module (cryptographically safe) instead of `random`.

## Features
- Custom length (minimum 8)
- Guarantees at least one lowercase and one uppercase letter
- Optional digits and symbols

## Requirements
- Python 3.8+

## How to Run
```bash
python password_generator.py
```

## Sample Output
```
Password length (min 8): 14
Include digits? (y/n): y
Include symbols? (y/n): y

Generated password: k#8Tq!Zr2$mLw9
```
