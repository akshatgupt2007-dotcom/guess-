# Number Guessing Game (Python)

A simple command-line game where you guess a secret number between 1 and 100 in 7 attempts. The program gives "too high" / "too low" hints.

## Concepts Used
- `random` module
- Loops and conditionals
- Exception handling (`try/except`)
- Functions

## Requirements
- Python 3.8+

## How to Run
```bash
python guess.py
```

## Sample Output
```
I'm thinking of a number between 1 and 100.
Attempt 1/7 - your guess: 50
Too low!
```
