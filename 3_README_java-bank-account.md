# Bank Account Simulator (Java)

A menu-driven console program that demonstrates object-oriented programming: create an account, deposit, withdraw and check balance.

## Concepts Used
- Classes, objects, encapsulation (`private` fields)
- Methods and input validation
- `Scanner` for input
- `switch` expressions (Java 14+)

## Requirements
- JDK 14 or higher

## How to Run
```bash
javac BankAccount.java
java BankAccount
```
