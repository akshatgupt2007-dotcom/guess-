# Prime Number Finder (C)

Prints all prime numbers up to a limit entered by the user, and counts them.

## Concepts Used
- Functions and `bool` type
- Loops and conditions
- `math.h` (`sqrt`) for an efficient check
- Input validation with `scanf`

## Requirements
- GCC (or any C compiler)

## How to Run
```bash
gcc primes.c -o primes -lm
./primes
```

## Sample Output
```
Print all prime numbers up to: 20
Primes up to 20:
2 3 5 7 11 13 17 19

Total primes found: 8
```
